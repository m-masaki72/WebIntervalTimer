インターバルタイマーについて

筋トレ・ポモドーロ・勉強など、複数のインターバルを組み合わせたトレーニングメニューをブラウザだけで管理できるタイマーです。

インターバル音とサイクル音を別々に設定でき、円形のプログレスバーで残り時間を直感的に把握できます。ホーム画面にインストールすれば、ジムや外出先でもオフラインで動作します。

使い方

  1. インターバル（ラップ）の時間を追加して、メニューを組み立てます。
  2. 繰り返すサイクル数と、インターバル音・サイクル音を選びます。
  3. スタートボタンを押すと計測が始まり、区切りごとに通知音が鳴ります。

主な機能・特徴

  • 複数インターバルの組み合わせとサイクル数の設定
  • インターバル音・サイクル音を個別に選択
  • 円形プログレスバーで残り時間を表示
  • Web Audio API で通知音を生成（音声ファイル不要）
  • PWA対応：ホーム画面に追加してオフライン動作

よくある質問

無料で使えますか？
はい。無料で、会員登録やアプリのインストールも不要です。ブラウザでこのページを開くだけで使えます。
オフラインでも使えますか？
はい。一度開いたあとはホーム画面に追加することで、通信がない場所でも動作します。
